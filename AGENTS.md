# KairOS_Protocol — instrucciones para agentes

Este repo reúne varios protocolos de trabajo. Cada uno tiene sus propias reglas, y las de uno no obligan a los demás. Índice y criterios de elección: `PROTOCOLOS.md`.

Antes de actuar, identifica bajo qué protocolo trabajas y lee solo sus reglas:

- **DIA** (Diseñar · Implementar · Auditar, trabajo atendido con Pi + ODD): `dia/README.md`.
- **Metis** (preparación y trains desatendidos hasta PR): `metis/README.md`.
- **Atenea** (flujo sobre OpenCode V2 + skills de Matt Pocock, C-087): `atenea/AGENTS.md`. Si cambias algo de Atenea (`docs/`, `tools/`, `.opencode/`), sus reglas son obligatorias.

Si no está claro qué protocolo aplica, pregunta a Sil antes de escribir.

Reglas comunes a todo el repo: sin push, PR ni merge sin GO explícito de Sil; no reescribir evidencias históricas (`historical/`, `qualification/`, documentos fechados ya cerrados); datos sintéticos.
